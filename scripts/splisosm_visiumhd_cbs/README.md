# Running SPLISOSM analysis for Visium HD mouse CBS datasets

This folder contains the workflow and visualization helpers for the SPLISOSM SV/DU
analysis of the mouse coronal brain section (CBS) Visium HD comparison.
Specifically, the workflow is configured to run on three datasets:

- 3' short-read TREND peaks
- FFPE targeted probes
- ONT transcript isoforms

For SV analysis, we test genes across three resolutions: 16um, 8um, and 2um. 
For DU analysis, we test one resolution (16um) using conditional association 
(`hsic-gp`, `cov_only`), crossing all SVP genes with a combined regulator design matrix 
containing both RBP and TF-ChIP covariates. The workflow is supported by the 
`SplisosmFFT` class for scalable FFT-based implementations.

Caches fingerprint nested Zarr files, installed SPLISOSM/analysis source, and
outputs. ReMap TF/interval caches also track the source BED and parser;
annotation caches detect changed reference files. 
Source fingerprints ignore Python comments, docstrings, formatting, and log-message
wording. Only imported shared helpers and their dependencies are included; SONIC
code/version changes do not invalidate SPLISOSM caches. 

## Minimal Dependencies

This workflow can run from the same shared `sonic_paper_splisosm` conda environment as
the [Atera analysis](../splisosm_atera_brca/README.md):

```bash
mamba create -y -n sonic_paper_splisosm -c conda-forge -c bioconda \
  python=3.12 numpy pandas scipy finufft matplotlib anndata spatialdata pybigwig \
  jupyter nbconvert ipykernel ruff samtools bedtools stringtie subread \
  htslib pip
conda run -n sonic_paper_splisosm python -m pip install splisosm==1.2.0
```

Python requirements used directly by these scripts are `splisosm`, `numpy`,
`pandas`, `scipy`, `finufft`, `matplotlib`, `anndata`, and `spatialdata`. The notebook also
uses `jupyter`, `nbconvert`, and `ipykernel`. `ruff` is only needed for code
formatting and checks. The Visium HD CBS workflow itself does not require the [Atera
TCGA command-line tools](../splisosm_atera_brca/ankrd30a/tcga.py), but they are included in `sonic_paper_splisosm` so both
analysis folders can share one environment.

If importing `spatialdata` raises a Numba cache error on this machine, rerun
with `NUMBA_DISABLE_JIT=1`.

## How To Run

Use `workflow.py` to compute result tables, and the notebook `visualization.ipynb` 
for interactive plotting surface.

All commands assume the repository root is the current working directory.

```bash
conda run -n sonic_paper_splisosm python scripts/splisosm_visiumhd_cbs/workflow.py --n-jobs 8
```

Use `--force` to recompute cached outputs:

```bash
conda run -n sonic_paper_splisosm python scripts/splisosm_visiumhd_cbs/workflow.py --force --n-jobs 8
```

Runtime settings, data paths, fixed kernel degrees, optional gene/RBP/TF
subsets, and output folders live in `config.py`.

## Outputs

Results are written under:

```text
results/splisosm_visiumhd_cbs/
```

This results directory is treated as a generated cache. It intentionally has no
separate README; this file is the maintained documentation for both scripts and
cached outputs.

Main cached files:

- `sv_<dataset>_<resolution>_hsic_ir.csv`
- `du_regulator_<dataset>_16um_hsic_gp.csv`
- `runtime_memory_metrics.csv`
- `shared_svp_hits.csv`
- `du_rbp_shared_associations.csv`
- `du_tf_chip_shared_associations.csv`
- `workflow_manifest.json`
- `cache_manifest.json`

Figures are not generated by the workflow. The notebook has explicit
publishable figure cells for the final PDFs:

- `svp_summary.pdf`
- `mbp_du_regulator_summary.pdf`
- `gabbr1_du_regulator_summary.pdf`

Exploratory cells show figures inline by default and can be edited for
custom gene inspection.
Cross-resolution, cross-platform, and DU pairwise agreement summaries are
computed inside the notebook from cached result tables rather than stored as
separate CSVs.

## Analysis Policy

- SV is run at 16um, 8um, and 2um.
- Filtering is selected at 16um and reused at finer resolutions.
- Fixed `neighbor_degree`: 16um=`1`, 8um=`4`, 2um=`64`.
- Fixed `rho`: `0.99`.
- DU is run at 16um only with `hsic-gp` and `residualize="cov_only"`.
- DU targets default to dataset-specific 16um SVP genes
  (`SV pvalue_adj <= 0.01`), crossed once with one combined regulator
  design matrix containing configured RBP covariates plus ReMap mouse
  TF-ChIP covariates. RBP and TF summaries are derived by filtering the
  single combined DU result table.
- DU RBP/TF covariates are filtered per dataset before testing: at least
  10 total aggregated counts and expression in more than 0.1% of bins.
- Optional subsets are explicit config values, not debug-mode flags.

The TF-ChIP covariate list comes from ReMap 2022 mouse non-redundant
`mm39` peaks. The workflow caches the large source BED and derived TF
target list under `~/reference/ReMap2022/`.

## Reference Structure Helper

`reference_annotations.py` loads cached reference annotations, and
`plotting.py` contains notebook-friendly plotting helpers:

```python
from scripts.splisosm_visiumhd_cbs.reference_annotations import load_reference_feature_cache
from scripts.splisosm_visiumhd_cbs.plotting import plot_feature_structure

ref_cache = load_reference_feature_cache()

plot_feature_structure(
    "Gabbr1",
    ref_cache,
    ref_list=["*-201", "*-202", "*-203", "*-209"],
    ont_tx_list=[
        "ENSMUST00000025338",
        "ENSMUST00000172789",
        "ENSMUST00000172792",
        "ENSMUST00000174456",
    ],
    probe_list=[],
    trend_list=[],
)
```

`load_reference_feature_cache()` parses the reference GTF, ONT GFF,
3' TREND BED12, and FFPE probe BED once. `plot_feature_structure()`
then draws selected or default reference transcripts, ONT isoforms,
FFPE probes, and 3' TREND peaks for one gene.

Subset arguments accept exact IDs/names or shell-style wildcards.
Empty lists suppress that feature class.
